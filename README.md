# K1_Android_FPS_Fix
Fix for KOTOR 1 FPS on Android. This KernelSU module applies a 60 FPS patch, and a 120 FPS patch to K1. Simply install, and do a soft reboot in KSU, then tap action and it'll set 60 FPS, tap action again and it'll increase it to 120 FPS, plus fix the combat being frozen beyond 60FPS.
